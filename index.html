PrintNest — deployment problem

This site was published without being built

What you are looking at is PrintNest's source index.html. It asks the browser for /src/main.ts, and a browser cannot run TypeScript — so the application never starts. Nothing is wrong with the code.

The fix is to publish the dist folder that npm run build produces, rather than the repository root:

Build command npm run build
Output directory dist
Node version 22 or newer

Full walkthrough in documentation/cloudflare-pages.md. If you are not the person who deployed this, hello@storitellah.com will reach someone who can fix it.
